# Repair Service MVP 🔧

Backend MVP-система для управления заявками на ремонт техники.

Проект реализован на **FastAPI** и предназначен для автоматизации процесса обработки заявок: от создания обращения клиента до диагностики, ремонта и выдачи результата.

---

🚀 Возможности

# Клиент

* Проверка статуса заявки по ID.
* Получение информации о текущем этапе ремонта.
* Получение контактов оператора.

### Оператор

* Создание новых заявок.
* Просмотр списка заявок.
* Удаление заявок.

### Инженер

* Просмотр всех заявок.
* Отметка о завершении диагностики.
* Передача заявки на следующий этап.

### Мастер по ремонту

* Просмотр заявок.
* Отметка о завершении ремонтных работ.

### Администратор

* Просмотр всех заявок.
* Управление кодами доступа сотрудников.
* Создание базы данных.
* Деактивация сотрудников.

## 🏗 Архитектура проекта

```
.
├── main.py
├── database.db
└── src
    ├── models.py
    ├── shemas.py
    ├── databases
    │   └── database.py
    ├── auth
    │   └── auth.py
    └── api
        ├── roles
        │   ├── admin.py
        │   ├── client.py
        │   ├── engineer.py
        │   ├── operator.py
        │   └── repairer.py
        └── services
            ├── services.py
            ├── services_admin.py
            ├── services_client.py
            ├── services_engineer.py
            ├── services_operator.py
            └── services_repairer.py
```

Архитектура разделена на:

* **models** — модели базы данных;
* **schemas** — Pydantic-схемы для API;
* **roles** — API-эндпоинты разных пользователей;
* **services** — бизнес-логика;
* **auth** — авторизация и JWT-проверка.

# 🔐 Авторизация

В проекте используется JWT-аутентификация.

Сотрудники получают уникальный код доступа, который хранится в базе данных в виде SHA-256 хеша.

После входа пользователь получает JWT-токен:

```
Authorization: Bearer <token>
```
